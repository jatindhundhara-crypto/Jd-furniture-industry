# JD Furniture Industry Website

A premium, responsive React + Vite website for JD Furniture Industry.

## Included
- Premium responsive design
- Home, About, Products, Custom Furniture, CNC, Gallery and Contact sections
- Product search and category filtering
- Gallery filtering and lightbox
- WhatsApp enquiry buttons
- Click-to-call
- Google Maps and Instagram links
- Custom enquiry form with image upload UI
- SEO metadata
- No fake prices or fabricated customer reviews

## Run locally
1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Build for production
npm run build

The production files will be in `dist/`.

## Deploy
Vercel / Netlify / Hostinger (Node/static hosting) can host the generated `dist` build.

## Replace images
The demo uses Unsplash furniture imagery. Replace image URLs in `src/main.jsx` with JD Furniture Industry's actual product and workshop photos for the final brand site.

## Important
The enquiry form currently shows a confirmation locally. For production lead collection, connect it to an email/form backend or CRM. WhatsApp buttons are already wired to +91 80056 04653.
